# Honda-Pilot-Financial-Analysis


## About This Project

This project analyzes Honda Pilot sales trends using monthly and annual sales data. The analysis includes descriptive statistics, year-over-year growth calculations, financial statement analysis, and sales forecasting using moving average and exponential smoothing methods. Forecasting models are evaluated using Mean Absolute Deviation (MAD) and Root Mean Square Error (RMSE) to examine historical sales patterns and generate short-term sales forecasts.
